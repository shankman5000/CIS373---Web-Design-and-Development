# Twin Cities Animal Rescue — Touchstone 3

A four-page educational sample website built from the original Touchstone 2 HTML and Sophia-provided media.

## Preview locally
Open `index.html` in a browser. All paths are relative.

## Publish
Create a public GitHub repository and upload the contents of this folder (not the enclosing folder). In repository Settings > Pages, publish from the main branch root to create a live preview URL.

## Notes
The contact form demonstrates browser validation only and is not connected to a server. Organization history, statistics, and partners remain explicitly unverified rather than invented.
